# Task Manager Application

This is a simple Task Manager application built using **React + TypeScript + Vite**.

The application allows users to create, view, update, and delete tasks.  
Data persistence is handled using **JSON Server** to simulate a real backend API.

## 🛠 Tech Stack

- React (Vite)
- TypeScript
- JSON Server
- Fetch API

## Repository Setup (https://github.com/nehali3026/task-manager.git)

git clone https://github.com/nehali3026/task-manager.git

cd task-manager

# Install Dependencies

npm install

# Run JSON server

npm run server (http://localhost:5000/)

# Run the Frontend

npm run dev (http://localhost:5175)
